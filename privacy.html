Privacy policy

This policy applies to the besacenselle comment moderation tool. Last update: 2026-11-08.

Data the tool reads

With the YouTube Data API, the tool reads the comments on the videos of the besacenselle channel. It reads no other data from Google accounts.

What the tool does with the data

The tool checks each new comment against the moderation rules of the channel. It sets bad comments to "held for review" on YouTube. It does nothing else with the data.

Storage and sharing

The tool keeps its login token and a list of the comments it has checked only on the computer of the channel owner. It sells no data and shares no data with other people. It shows no ads.

To check a comment, the tool sends the comment text to the Claude model of Anthropic, through the Claude account of the channel owner.

Removal of access

The channel owner can remove the access of the tool at any time at myaccount.google.com/permissions.
